# Binary Search Tree Fusion

This project implements the fusion of Binary Search Trees (BSTs) using different traversal strategies as part of a data structures practical assignment.

## Project Objective

The goal is to merge two binary search trees into a third BST while comparing different traversal methods:
- Inorder
- Preorder
- Postorder

The project evaluates how traversal order impacts the structure and quality of the resulting tree.

## Implementations

The project includes:
- A Khawarizm (.alg) implementation
- A C language implementation generated and adapted from the algorithmic version

## Features

- Random BST generation
- BST fusion algorithms
- Multiple traversal combinations
- Validation of the resulting tree
- Performance and structural comparison

## Traversal Cases Studied

1. Inorder / Preorder
2. Inorder / Postorder
3. Preorder / Preorder
4. Postorder / Postorder
5. Preorder / Postorder

## Technologies

- C
- Khawarizm
